Вопросы к документу

Загрузите документ, задайте вопрос — ответ строится только по тексту, со ссылкой на источник. Эмбеддинги считаются локально, ответ формирует языковая модель.

Что это и зачем

  • Обычный чат-бот не знает ваши документы и может выдумать ответ.
  • RAG отвечает строго по загруженному тексту и показывает, из какого фрагмента взят ответ.
  • Применение: чат с PDF, база знаний, поддержка по инструкциям, поиск по договорам и конспектам.
